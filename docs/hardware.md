# 已知硬件规格

来源：官方发布信息、媒体报道、社区逆向项目（主要是 `pablo-mano/microduck-replica` 与 `SaberOnGo/open-microduck`）。调研日期 2026-09-14。

标注 ⚠️ 的条目存在来源冲突或未经硬件验证，见 [open-questions.md](open-questions.md)。

## 整机

| 项 | 值 |
|---|---|
| 高度 | ~25 cm |
| 重量 | ~800 g |
| 形态 | 单眼双足 |
| 负载 | 喙部可抓取 ≤800 g 物体 |
| 官方配色 | 奶油、石墨、薰衣草紫、天蓝 |
| 售价 | $399 |

已知能力：行走、下蹲、常见跌倒恢复、喙部抓取、轮滑。

## 计算与控制

| 项 | 值 |
|---|---|
| SoC | Rockchip RK3566 |
| 主板 | Radxa Zero 3W（现成模块，非定制板） |
| 控制环频率 | 50 Hz |
| 自定义 PCB | RPI Robot HAT（官方已开源 KiCad）、`imu_to_dxl`（未公开）⚠️ |

主板是现成的 Radxa Zero 3W 这一点很关键 —— 计算侧不需要复刻，直接买。

## 执行器

| 项 | 值 |
|---|---|
| 舵机 | Dynamixel XL330 × 15 |
| 运动 policy 控制关节数 | 14（policy 输出 14 维） |
| 总线 | Dynamixel 协议 |

15 个电机 ID 与 14 个 policy 输出的差值，推测是喙部或头部由独立逻辑控制，未确认。

## 传感器

| 项 | 型号 | 备注 |
|---|---|---|
| 摄像头 | IMX219 | 树莓派生态常见模块 |
| ToF / 深度 | VL53L8CX | 由 `tofd` 驱动 |
| IMU | LSM6DSV16X | 数量存疑：部分来源称两个 IMU ⚠️ |
| NFC 读头 | — | 2 个，型号未知 ⚠️ |
| 麦克风 | — | 型号未知 |
| 扬声器 | — | 型号未知 |

## 电源

| 项 | 值 |
|---|---|
| 电池 | Sony NP-F550 |

选用摄像机通用电池而非定制电芯，对复刻是好消息 —— 易采购，有现成卡座。

## 紧固件与结构

| 项 | 值 |
|---|---|
| 紧固件 | ~325 个，M2 体系 |
| 刚体数 | 15 |
| 仿真网格 | 47 个 STL |

数量来自 replica 项目对 MJCF geom 引用的统计，非估算。但仿真 STL 不是制造文件，实际打印需要公差迭代。
