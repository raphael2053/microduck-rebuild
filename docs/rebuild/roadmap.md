# 复刻 Roadmap

目标：**做出一台会走路的 Microduck**。

路线切换日期 2026-09-16。依据是两个社区项目当时的进度与国内供货实况。上游生态变化快，超过一个月请重新核实。

---

## 路线决定：走 fanhao375 路线（飞特 HD-1910）

**跑官方 Rust 栈，舵机换国产飞特 HD-1910-C001，两块板自己打样。**

### 为什么从 AI-FanGe 换过来

原先选 AI-FanGe 是因为它**被验证走通了**（实机行走视频 + 零自制 PCB）。推翻它的是采购实况：

| | 单价 ×14–15 | 交期 |
|---|---|---|
| XL330 @ Seeed | ¥3100 | ❌ **4–6 周**，且"付款后才开始生产" |
| XL330 @ 淘宝 | ¥9800–14000 | 快，但贵到离谱 |
| **飞特 HD-1910 @ ¥122** | **¥1830**（15 颗） | ✅ **15 天内** |

Seeed 三个仓的 In Stock 全是空的，只有中国仓能 Back Order。**又便宜又快的只有飞特。**

### 换过来得到什么

- **成本降到约 1/2 – 1/5**，交期从 4–6 周降到 15 天
- **力矩 2.5 倍**（1.47 N·m @7.4V vs 0.52 N·m @5V）
- ✅ **不再超压运行** —— XL330 在这台机器上是超出额定 37% 跑的，HD-1910 的 4–8.4V 完整覆盖 2S 母线
- **齿轮虚位更小**（≤0.5° vs 建模 ±1.0°）
- **文档密度高一个量级** —— fanhao375 有 31 份中文文档：硬件入门、逆向推导、采购清单、构建日志、踩坑记录、调试记录

### 代价说清楚

⚠️ **这条路线没有人走通过。** fanhao375 已装出整机（2026-09-16 时点：15 颗 HD-1910 配好 ID 装机完成），但**台架通总线仍在进行中**，`imu_to_dxl` 还在等打样。

三项在 AI-FanGe 路线下不存在的工作回来了：

| 工作 | 说明 |
|---|---|
| **两块 PCB 打样** | Robot HAT（官方开源，照打）+ `imu_to_dxl`（⚠️ 社区重建，**从未流片验证** —— 全项目风险最高的单点） |
| **协议模块替换** | 飞特走 STS 不是 Dynamixel v2。⚠️ `rustypot` 有 `Sts3215PyController` 但**无 HD-1910 的类**，兼容性未验证 |
| **策略全部重训** | 官方 9 个 ONNX 是在 XL330 动力学上训的。阶段 0 已实验确认接口相容不等于可用 |

**什么情况下改回去**：XL330 恢复正常供货且价格回到 ¥250 以内；或 `imu_to_dxl` 打样后反复失败。

## 关键路径

舵机 15 天、PCB 打样约 1 周。**先下单、先发板，等货期间做打印与软件。**

```
0 仿真 ✅ → 1 下单+发板 → 2 打印 → 3 配 ID → 4 装配
                   ↓                      ↓
              5 电控验证 ←────────────────┘
                   ↓
         6 刷机+协议适配 → 7 策略重训 → 8 首次行走
```


## 阶段 1 · 下单与 PCB 打样

完整清单见 **[../../hardware/bom.md](../../hardware/bom.md)**。

两件事**同时启动**，都是关键路径：

**下单**：飞特 HD-1910-C001 ×15、Radxa Zero 3W（2G/16G）、NP-F550 电池与仓、VL53L8CX、IMX219、轴承、紧固件、线材、飞特调试板 FE-URT-2。

**发板**：Robot HAT 按官方 gerber 打样；`imu_to_dxl` 按 fanhao375 的嘉立创工程打样。

⚠️ **建议先只买 2 颗 HD-1910 验协议**，别一次买 15 颗。换舵机的第一个风险点是协议不是力矩 —— 接上 `rustypot` 看能不能读到位置，这个实验做完再全量采购。和阶段 0 一个思路：最便宜的失败要先失败。

**完成判据**：物料下单，两块板已发出打样。

## 阶段 2 · 打印结构件（飞特版）

⚠️ **必须用飞特版，不是上游原版。** HD-1910 舵盘凸、XL330 凹，**8 个配合件不同**。

fanhao375 已发布：拓竹 MakerWorld 一键打印、`.3mf`、SolidWorks 图纸 v2.0（文件带 `-FT` 后缀）。

材料 PLA。**先把文件存到本地**，别指望上游一直在。

**完成判据**：结构件打印完成，目测无明显翘边分层。

---

## 阶段 3 · 舵机配 ID（最容易翻车的一步）

用飞特 **FD 调试软件** + **FE-URT-2** 调试板逐个设置。

- ⚠️ **一次只接一颗** —— 出厂 ID 全是 1，同时接上全都应答，分不出谁是谁。改完立刻贴标签，拔掉，换下一颗
- ⚠️ **HD-1910 的线是 2.0mm，FE-URT-2 的口不是** —— 插不上，当天要配 ID 得剪一根舵机线飞线。正式做法是买 PH2.0 3P 端子线对焊转接线
- ⚠️ **脚序与 Dynamixel 完全相反**：飞特 `1=Signal 2=Vcc 3=GND`。**中间那根一定是 V，V 接错才会烧**
- ⚠️ 装机前把舵机的**过流、过压保护打开**（出厂默认关闭）

ID 映射：左腿 20–24 / 颈头嘴 30–34 / 右腿 10–14。

⚠️ **FD 软件和驱动在 Gitee 不在官网**，fanhao375 仓库的 `tools/飞特/` 里有存档。

**完成判据**：15 颗 ID 正确、已贴标签、FD 能逐个点亮。

## 阶段 4 · 装配

把配好 ID 的舵机装进打印件。参考 fanhao375 的 `构建日志.md` 与 `踩坑记录.md` —— 他已经走完这一步。

**完成判据**：整机组装完成，关节能手动活动无干涉。

## 阶段 5 · 电控验证（全项目风险最高）

两块板回来后上电验证。**不要装进机身，先台架。**

- Robot HAT：官方开源件，风险低
- ⚠️ **`imu_to_dxl`：从未有人流片验证过。** 有两份独立的社区重建（fanhao375 与 pablo-mano），对上则可信度大增，对不上说明至少一份有问题
- ⚠️ 上电前用万用表确认正负极；焊点要绝缘

⚠️ **串口控制台会抢总线** —— Armbian 默认在 UART2 跑登录控制台，`agetty` 占着口会让舵机对其他进程完全不可见。`fuser -v /dev/ttyS2` 查谁占着。

**如果 `imu_to_dxl` 失败**：fanhao375 有一份「不打 HAT」的替代方案（¥70 的降压模块 + 半双工转接板飞线），可作退路参考。

**完成判据**：上电不冒烟，15 颗舵机 + id 200 全部在总线上应答。

---

## 阶段 6 · 刷机与协议适配

主控刷 Armbian，跑官方 Rust 栈，替换总线协议模块。

- 镜像：Armbian Debian 13 (trixie) · minimal · vendor 内核 6.1.115
- ⚠️ **协议模块** —— 飞特 STS 不是 Dynamixel v2。先验证 `rustypot` 的 `Sts3215PyController` 能否驱动 HD-1910；不行就要自己实现

**完成判据**：`robotd` 起得来，能读到全部 16 个设备，`robot.health` 返回健康。

---

## 阶段 7 · 策略重训

本路线独有的大块工作。流程与状态机见 [../../software/AGENTS.md](../../software/AGENTS.md)。

1. **台架实测** HD-1910 的执行器参数（fanhao375 提供了《HD-1910 训练前数据清单》，标明哪些项要实测）
2. 写进 `joints_properties.xml` 的 BAM 参数
3. mjlab PPO 训练 —— CUDA GPU，或 HF Jobs（实测 103 分钟 / $3.15）
4. `scripts/export.py` 导出 ONNX。⚠️ **别手工转 checkpoint**，观测归一化被烘进计算图
5. `infer_policy.py` 仿真验证

**完成判据**：仿真里鸭子站得住、走得动。

**完成判据**：鸭子走起来了。**到这里复刻目标达成。**

## 风险清单

| 风险 | 概率 | 后果 | 对策 |
|---|---|---|---|
| **`imu_to_dxl` 打样失败** | **高** | 阻塞阶段 5 | 两份独立重建交叉比对；退路是「不打 HAT」方案 |
| **`rustypot` 不支持 HD-1910** | **中高** | 要自己实现协议 | **先买 2 颗验证**，别等全量到货才发现 |
| 重训后 sim2real 差距大 | 中 | 反复迭代 | 台架标定做扎实；参考《训练前数据清单》 |
| 舵机 ID 配错 | 高 | 关节乱动，难排查 | 一次一颗 + 贴标签 |
| 接线烧件 | 中 | 烧舵机或主控 | 脚序与 Dynamixel 相反，压完先用万用表点一遍 |
| 电池满电无余量 | 中 | 触发过压保护 | 8.4V 顶格，刚充满别直接堵转测试 |
| 上游仓库变动 | 中 | 文档与实际不符 | 打印文件、镜像、图纸先存本地 |
